# أداة حموشي لتحليل ملفات نتائج الطلبة (PDF)

تطبيق ويب مبني بـ Streamlit يقوم بـ:
1. **فك تشفير تلقائي** لملفات PDF التي تستخدم ترميز خط عربي غير قياسي (المشكلة
   التي واجهناها مع بعض ملفات نتائج وزارة التربية). يُعاد بناء خريطة الترميز
   لكل ملف يُرفع تلقائيًا، لأن كل ملف قد يحمل خريطة مختلفة حتى لو تشابه اسم الخط.
2. **تبويب البحث:** ابحث عن اسم طالب/طالبة (أو أي كلمة) عبر كل صفحات الملف.
3. **تبويب الإحصائيات:** لملفات قوائم المعدلات (ت / المعدل الأصلي / درجة
   اللغات / الإضافة / المعدل بعد الإضافة) — إضافة درجة، عدد الطلبة حسب كل
   فئة، حساب أدنى معدل ضمن أعلى N طالب، وتنزيل النتائج كملف Excel.

---

## أبسط طريقة لنشر الموقع (مجانية بالكامل)

### الخطوة 1: أنشئ حساب GitHub (إن لم يكن لديك)
اذهب إلى https://github.com وأنشئ حسابًا مجانيًا.

### الخطوة 2: ارفع ملفات المشروع
أنشئ "New repository" جديد (يمكن أن يكون خاص Private)، وارفع هذه الملفات
الثلاثة التي أرسلتها لك:
- `app.py`
- `font_decoder.py`
- `parser_averages.py`
- `requirements.txt`

يمكنك رفعها مباشرة من متصفح GitHub بالسحب والإفلات (زر "Add file" → "Upload files").

### الخطوة 3: أنشئ حساب Streamlit Community Cloud
اذهب إلى https://share.streamlit.io وسجّل الدخول باستخدام حساب GitHub نفسه (مجاني تمامًا).

### الخطوة 4: انشر التطبيق
- اضغط "New app"
- اختر الـ repository الذي رفعته
- اختر الملف الرئيسي: `app.py`
- اضغط "Deploy"

خلال دقيقة أو دقيقتين سيصبح موقعك جاهزًا برابط دائم مثل:
`https://your-app-name.streamlit.app`

يمكنك مشاركة هذا الرابط مع أي شخص، وسيعمل الموقع من أي جهاز (لا حاجة لتثبيت شيء).

---

## تشغيل التطبيق محليًا على جهازك (اختياري، لتجربته قبل النشر)

```bash
pip install -r requirements.txt
streamlit run app.py
```

سيفتح الموقع تلقائيًا في المتصفح على `http://localhost:8501`

## ملاحظات مهمة

- **حجم الملفات:** الملفات الكبيرة جدًا (بضع مئات من الصفحات فأكثر) قد تستغرق
  دقيقة أو أكثر لمعالجتها في المرة الأولى؛ التطبيق يخزّن النتيجة مؤقتًا (cache)
  حتى لا يعيد المعالجة إذا بحثت أكثر من مرة في نفس الملف.
- **إذا واجهت ملفًا لا يعمل معه فك التشفير:** أرسل لي نموذجًا وسأحدّث الكود؛
  كل مولّد PDF مختلف قد يحتاج تعديلًا بسيطًا في طريقة استخراج النص.
- **الخصوصية:** في Streamlit Community Cloud المجاني، أي ملف تُحمّله لا يُخزَّن
  بشكل دائم على خوادمهم لكنه يمر عبر خدمتهم لمعالجته. إن كانت البيانات حسّاسة
  جدًا (كأسماء طلبة حقيقية)، ننصح بتشغيل التطبيق محليًا فقط بدل نشره علنًا،
  أو استخدام خطة خاصة/داخلية بدل الطبقة المجانية العامة.
